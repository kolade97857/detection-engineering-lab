# Detection Investigations

## Workflow
1. Review the alert, timestamp, severity, and reason.
2. Collect relevant Windows and Sysmon events.
3. Build a timeline using timestamps, host, user, process, and other fields.
4. Assess alternative explanations and possible false positives.
5. State a conclusion supported by evidence.
6. Recommend proportionate follow-up actions.

## Report template
Include title/date, alert, objective/scope, data sources, SPL queries, timeline, evidence, findings, ATT&CK mapping where applicable, false-positive considerations, conclusion/confidence, recommendations, and evidence references.

All investigations must be conducted in an authorized lab. Exclude secrets and personal information. A detection match alone does not prove malicious activity.
